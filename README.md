# באגט ניר – טבריה

אתר נחיתה סטטי בעברית (RTL): HTML, CSS ו-JavaScript בלבד.

## תצוגה מקומית

```bash
cd "/Users/israeltesler/.cursor/באגט ניר"
python3 -m http.server 8080
```

פתח: `http://localhost:8080`  
אפשר גם לפתוח ישירות את `index.html` בדפדפן.

## מה כבר מוגדר

- עיצוב שחור וזהב, מובייל קודם + סרגל פעולות תחתון
- **תפריט ומחירים אמיתיים** לפי צילום לוח התפריט (`assets/img/menu-board.png`)
- כשרות מהדרין (ללא מספר תעודה)
- שעות: א'–ה' 10:30–01:00 (למחרת), שישי — שעות קצרות (placeholder), שבת סגור
- סטטוס פתוח/סגור אוטומטי ב-`assets/js/main.js`
- ביקורות — ציטוטים בלבד
- תמונת לוח התפריט מוצגת בסעיף התפריט
- תמונת Hero אמיתית (`assets/img/hero-food.webp`)
- לוגו שקוף שחולץ מהצילום, ללא רקע (`assets/img/logo.png`)

## כתובת (מוגדר)

**אלחדיף 3, טבריה** — ב-Hero, ביצירת קשר, בפוטר, ב-SEO ובקישורי Waze/Google Maps.

## קבצים

- `index.html` — מבנה העמוד
- `assets/css/style.css` — עיצוב
- `assets/js/main.js` — תפריט, שעות, סטטוס
- `assets/img/menu-board.png` — צילום לוח התפריט (מקור המחירים)
- `robots.txt`, `sitemap.xml` — stubs לפרסום

## עדכון מחירים

ערוך את המערך `MENU_ITEMS` ו-`EXTRAS` ב-`assets/js/main.js` רק לאחר צילום/אישור לוח תפריט מעודכן.
